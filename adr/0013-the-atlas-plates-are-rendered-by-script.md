# The atlas plates are rendered by script, because Layout Composer cannot be

The brief asked for a gallery of burn-area maps laid out with
[Layout Composer](https://github.com/Defani/Layout-Composer), the cartographic
layout plugin for GeoLibre.

Layout Composer is a plugin for the GeoLibre desktop application: a ribbon
editor driven by hand, installed by copying a zip into the app's plugin
directory. It has no command line and no headless mode. Its own README
documents the workflow as Insert, then Map, then drag a frame on the page, then
Export. Nothing in it can be called from a script, so the plates could not be
produced by a build or regenerated by anyone who re-runs this repository.

`scripts/burn_atlas.py` therefore composes the plates itself, with the same
anatomy Layout Composer would give them: a map frame with a coordinate
graticule, a locator inset, a date series, a scale bar, a north arrow, a
legend, a title block and a credits line. Every number on a plate is read from
the same files the web pages read, so a plate and the front page cannot
disagree.

## The hand-finished route stays open

Each plate ships with `docs/gallery/<event>.geolibre.json`: the same layers at
the same extent, as a GeoLibre project. Open it in GeoLibre with this
repository as the workspace, enable Layout Composer, and the frame is already
set up for a print layout.

The first version of that writer was written from the README and guessed the
schema — `view` for `mapView`, `basemap` for `basemapStyleUrl`, and a file path
where a vector layer wants its GeoJSON inlined. GeoLibre refused to open it.
The schema the script writes now was taken from a project GeoLibre itself
created, and GeoLibre reads back every project the script writes.

## What a plate says, and what it does not

The hectares on a plate are a mapped extent: what the dNBR+ product drew inside
that event's footprint. No interval, and not the validated area. The validated
estimate covers these three footprints together and falls above what the
product maps across them, which ADR 0010 already states and the gallery page
repeats in the reader's own words.

Only three events have plates. They are the three with hand-drawn
interpretation boxes and 1 m imagery. Every other event is mapped from 20 m
bands, which is a limit of the imagery and not a judgement about those fires.
