# Tailwind comes from a CDN; the webfonts come from this origin

The brief asked for the pages to be styled with Tailwind CSS. ADR 0002 says
there is no JavaScript toolchain in this repository, and that the daily cron
must not install a second language runtime every evening to save thirty lines
of duplication.

The two reconcile in exactly two ways: run the Tailwind CLI once by hand and
commit its output, or load the browser build and let it compile in the page.
The browser build was chosen. A committed stylesheet has to be regenerated by
whoever next edits a class name, and the person maintaining this repository
should not need Node installed to change the colour of a label.

`cdn.jsdelivr.net/npm/@tailwindcss/browser@4.1.18` is pinned, and
`test_pinned_cdn_only` carries that reason. It is the only script on the site
not pinned to a copy in this repository's own history.

## The cost, stated

The browser build is a compiler. It arrives over the network, it runs on every
page load, and until it has run the page is unstyled. The parts that must
survive that — the banner saying a data file failed to load, the
observation-gap box, the map frame, the type — are plain CSS in
`assets/site.css`, which loads first. A page that fails to say a file is
missing is worse than a page with no styling.

If that compile ever becomes the thing that makes this page slow on a
connection in Biak, the answer is the Tailwind CLI and a committed stylesheet,
not a smaller set of classes.

## The webfonts are not on a CDN

Source Serif 4 and IBM Plex Sans Condensed are committed under `site/assets/`
as latin-subset woff2 and served from this origin: 87 KB across three files.
Both are SIL OFL 1.1, which permits the redistribution, and
`assets/FONTS-LICENSE.txt` carries the notices.

Loading them from a font CDN would hand a third party one request per reader
per page, on a public monitoring page that otherwise asks nothing of anybody.
Serving them here also keeps them out of the host allowlist, where every entry
has to be a decision somebody made.

The serif is for prose and the condensed sans is for the map chrome, the tables
and the figures, where horizontal economy is what a dense panel needs.
